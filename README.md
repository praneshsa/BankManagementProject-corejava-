# Bank Management System

A console-based **Bank Management System** developed using Core Java. This project demonstrates object-oriented programming concepts and basic banking operations through a simple, menu-driven application.

## 🚀 Technologies Used

- **Core Java**
- Object-Oriented Programming (OOP)
- Java Collections / Arrays (as used in the implementation)

## ✨ Features

- Manage bank account details
- Perform basic banking operations
- Handle user input through the console
- Apply object-oriented programming concepts
- Organize program logic using Java classes and methods

*Note: The listed features should match the operations implemented in the source code.*

## 🛠️ Prerequisites

- Java Development Kit (JDK)
- IntelliJ IDEA, Eclipse, or any Java-supported IDE

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/praneshsa/BankManagementProject-corejava-.git
```

### 2. Open the project

Open the cloned project in your preferred Java IDE.

### 3. Compile the program

If running from the terminal, navigate to the directory containing your Java source files and compile the main class:

```bash
javac Main.java
```

### 4. Run the application

```bash
java Main
```

Replace `Main` with the actual main class name if it differs.
